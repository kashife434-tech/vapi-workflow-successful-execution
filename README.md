🚀 **New AI Automation Project: Vapi + n8n | Inbound Voice Customer Intake Agent**

I've been working on an AI-powered voice automation project that simplifies customer intake and appointment requests.

🤖 **Project Overview:**
Built using Vapi, n8n, and Google Sheets, this workflow receives incoming customer requests, validates information, and automatically stores complete records.

⚙️ **Key Features:**
- Inbound AI voice agent using Vapi
- Webhook integration with n8n
- Automated customer data extraction and mapping
- IF-based validation for required fields
- Google Sheets integration for storing customer requests
- Separate success and follow-up responses
- Error-handling considerations

🛠️ **Tech Stack:**
- Vapi
- n8n
- Google Sheets
- Webhooks
- JSON

📚 **What I Learned:**
This project helped me improve my understanding of voice AI agents, API integrations, workflow automation, data validation, and error handling.
